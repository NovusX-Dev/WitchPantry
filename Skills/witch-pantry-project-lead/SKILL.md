# Witch Pantry Project Lead

Use this skill to keep decisions shippable, sequenced, and honest about risk.

## Read First

1. Read:
   - `Docs/Witchs-Pantry-3-Month-Development-Roadmap.md`
   - `Docs/roadmap.md`
   - `Docs/Demo-and-Early-Access-Plan.md`
   - `Docs/Product-Strategy.md`
2. Read `references/sources.md` when milestone or process decisions need outside support.

## Core Workflow

1. Restate the deliverable in shipping terms:
   - prototype proof
   - vertical slice
   - demo content
   - Early Access system
   - polish or release-prep
2. Identify the smallest outcome that de-risks the most unknowns.
3. Separate:
   - core verbs/features
   - required content
   - nice-to-have polish
4. Expose dependencies and blockers explicitly.
5. Decide whether to:
   - commit
   - cut
   - defer
   - split
   - re-scope
6. End with a concrete next sequence, not a mood board.

## Leadership Rules

- Protect the product goal over local feature enthusiasm.
- Use prototypes to answer design questions; use vertical slices to test the production pipeline.
- Lock core verbs before expanding content breadth.
- Prefer one finished, representative slice over five half-systems.
- Treat hidden dependencies as schedule threats, not trivia.
- Use reviews as adaptation points, not ceremonial status theater.
- Cut scope before quality when the choice is between a shippable promise and a broken larger promise.
- Marketing timing follows clarity: the clearer the game, the easier honest messaging becomes.

## Risk Triage

- Flag work that depends on undefined data, absent tools, or unstable architecture.
- Flag any feature whose value is mostly hypothetical and whose implementation cost is concrete.
- Flag anything that creates long-tail content or support burden without strengthening the game's hook.
- If a task does not de-risk the critical path or strengthen the shipped experience, challenge it.

## Good Output Shape

End with:

- release target
- why it belongs there
- dependencies/blockers
- cut list or defer list
- immediate next 3 to 5 actions
