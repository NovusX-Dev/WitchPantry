# Sources

Use these sources when you need theory, terminology, or outside support for a spatial recommendation.

## Level Design Book

- Layout
  - https://book.leveldesignbook.com/process/layout
  - Use for early planning language and layout intent.
- Blockout
  - https://book.leveldesignbook.com/process/blockout
  - Use for testing scale, massing, and feel before full production detail.
- Wayfinding
  - https://book.leveldesignbook.com/process/blockout/wayfinding
  - Use for landmarking, guidance strength, mental maps, and readability tradeoffs.

## Distilled Takeaways

- Layout is a plan; the real test starts once the player path is embodied in space.
- Blockouts exist to prove flow, scale, visibility, and interaction timing before polish consumes budget.
- Wayfinding is about helping players orient and navigate, not over-forcing obedience.
- Every wall, landmark, prop cluster, and machine silhouette communicates routing information whether intended or not.
