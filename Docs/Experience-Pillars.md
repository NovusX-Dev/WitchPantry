# Experience Pillars

## Purpose

Use this document as the go or no-go filter for future features.

## Pillar 1: Readable Magical Productivity

Pass if the feature makes the pantry easier to understand, more satisfying to watch, or more clearly magical.

Fail if the feature adds invisible math without visible payoff.

## Pillar 2: Cozy Optimization

Pass if the feature deepens planning and organization without introducing harsh punishment.

Fail if the feature creates stress through opaque penalties or constant interruption.

## Pillar 3: Glanceable Persistence

Pass if the feature works in both active play and compact side-screen play.

Fail if the feature only makes sense in a fully expanded UI with constant clicking.

## Pillar 4: Marketable Clarity

Pass if the feature improves screenshot, trailer, or store-page communication.

Fail if the feature is hard to explain or impossible to show visually.

## Decision Checks

Ask these before approving any new feature:

- Does it improve screenshot readability?
- Does it deepen pantry optimization?
- Does it respect cozy tone?
- Does it support idle and desktop play?
- Can a new player understand its value quickly?
