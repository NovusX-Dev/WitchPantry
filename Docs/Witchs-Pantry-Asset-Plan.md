# Witch's Pantry Automation Asset Production Plan

- Engine: Unity 6; current project version: `Witch-Pantry/ProjectSettings/ProjectVersion.txt`
- Style: Stylized Fantasy 2D

Goal: define all art assets required to ship the game.

## 1. Art Direction

Style:

- Stylized fantasy
- Soft lighting
- Glowing magical effects
- Hand-painted UI

Color palette examples:

- Red: Health
- Blue: Mana
- Green: Poison
- Purple: Arcane
- Gold: Legendary

Each machine requires multiple sprites.

Machine list:

- Herb Garden
- Mortar Golem
- Cauldron
- Bottling Sprite
- Storage Shelf
- Fermentation Barrel
- Essence Distiller

Machine sprite states:

- Idle
- Working
- Completed cycle
- Upgrade visual state

Example for Cauldron:

- Idle bubbling
- Brewing animation
