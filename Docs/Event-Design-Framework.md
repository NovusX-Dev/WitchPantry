# Event Design Framework

## Event Taxonomy

### Positive Opportunities

- temporary production boosts
- premium buyers
- helper blessings

### Mixed Soft Friction

- a machine slowdown with a cheap fix
- a shelf blockage with a simple response
- weather that hurts one output but helps another

### Player-Triggered Gambles

- optional requests with higher rewards
- risky recipe opportunities
- special visitors with tradeoffs

## Hard Limits

- no major destructive loss
- no opaque punishment
- no long involuntary downtime
- always provide response or counterplay

## UX Rules

- event cause must be clear
- player response must be easy to understand
- rewards and risks must be shown before commitment

## Tone Rule

Events should add texture and decision-making without breaking the cozy promise.
