# Demo and Early Access Plan

## Demo Goal

Prove the hook quickly enough to earn wishlists:

```text
one readable magical pantry
-> visible production flow
-> clear customer demand
-> useful compact desktop mode
```

The demo should answer whether players understand and want the core fantasy, not whether the full content treadmill already exists.

## Demo Slice

Required:

- one memorable pantry room with a strong focal machine
- starter machine set that shows ingredient source, processing, brewing, and fulfillment
- one or two adjacency or placement decisions the player can understand visually
- customer demand loop with clear contract progress
- compact desktop-idler mode that preserves the main state
- save and offline progression sufficient for real check-in behavior
- one soft-friction event with obvious cause, response, and reward

Cut from demo unless already cheap:

- broad prestige system
- multiple full room chains
- deep faction reputation
- research trees beyond a small teaser

## Demo Feedback Hooks

Collect feedback on:

- first 10-minute comprehension
- pantry readability
- compact mode usefulness
- demand clarity
- perceived cozy tone
- whether players can describe the hook after one session

## Metrics to Watch

- time to first useful production line
- time to first visible bottleneck fix
- compact mode usage
- contract completion rate
- return after first idle/offline interval
- wishlist conversion signals from demo and store traffic

## Early Access Goal

Expand content and progression without losing the original hook.

Early Access should prove retention and breadth, not replace the core pantry fantasy with menu sprawl.

## Early Access Focus

- two to three connected rooms total
- more machine and ingredient depth
- stronger faction and visitor variety
- scoped prestige and research layers
- better balancing, save resilience, and offline simulation
- expanded event counterplay

## 1.0 Ladder

1. Demo proves the hook.
2. Early Access proves retention and breadth.
3. 1.0 proves completeness, polish, and replayable content depth.
