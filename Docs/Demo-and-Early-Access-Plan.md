# Demo and Early Access Plan

## Demo Goal

Prove the hook quickly and generate wishlists.

## Demo Slice

- one memorable pantry room
- starter machine set
- one or two adjacency bonuses
- customer demand loop
- useful compact desktop-idler mode
- save and offline progression
- first event examples

## Demo Feedback Hooks

Collect feedback on:

- first 10-minute comprehension
- pantry readability
- compact mode usefulness
- demand clarity
- perceived cozy tone

## Metrics to Watch

- time to first useful production line
- time to first visible bottleneck fix
- compact mode usage
- contract completion rate
- wishlist conversion signals from demo/store traffic

## Early Access Goal

Expand content and progression without losing the original hook.

## Early Access Focus

- more machine and ingredient depth
- more room growth
- more factions and visitors
- fuller prestige loop
- stronger balancing

## 1.0 Ladder

1. Demo proves the hook.
2. Early Access proves retention and breadth.
3. 1.0 proves completeness and polish.
