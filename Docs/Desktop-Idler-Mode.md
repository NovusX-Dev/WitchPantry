# Desktop Idler Mode

## Goal

Support a compact side-screen play pattern without making the game feel stripped down or unreadable.

## Window Behavior

- compact layout should fit a narrow desktop window
- core metrics stay visible at all times
- alerts should be concise and non-spammy

## Minimum HUD

- gold
- primary demand target
- potion throughput
- bottleneck status
- one to three quick actions

## Always-Glanceable Rules

- player should understand current state in under 5 seconds
- text must remain readable at compact scale
- top alerts should summarize action needed in plain language

## Reduced Interaction Model

- quick claim for rewards
- quick fix for simple event responses
- quick buy or upgrade suggestions
- compact toggle back to full management mode

## Success Criteria

- useful on a second monitor
- useful on the side of a large primary monitor
- not dependent on opening deep panels
- still clearly communicates the fantasy of a busy magical pantry
